# Manche Spiele sind bei mir nur teilweise übersetzt oder synchronisiert

Prüfe zuerst, **wo** etwas auf Englisch erscheint: im Spiel auf dem Computer, bei der Sprachausgabe oder auf dem Handy.

## Der Controller auf meinem Handy ist auf Englisch

Tritt über [Jackbox.de](../Wissenswertes/JackboxDE.md) bei. Texte und Grafiken des Browser-Controllers können unabhängig von den Dateien auf deinem Computer bereitgestellt werden. Ein installierter Deutsch-Patch übersetzt deshalb nicht automatisch alle Inhalte auf Jackbox.tv.

## Die Quizfragen in Trivia Murder Party 3 sind auf Englisch

Sind die Menüs deutsch, aber die Quizfragen englisch? Bei manueller Installation unter Windows muss die mitgelieferte Installationsdatei ausgeführt werden. Auch nach Spielupdates kann dies erneut nötig sein. Die vollständigen Schritte stehen unter [Trivia Murder Party 3: englische Quizfragen](../Spiele/trivia-murder-party-3.md#englische-quizfragen).

## Andere Spiele oder Inhalte

### Möglichkeit 1: Wir arbeiten derzeit noch an der deutschen Übersetzung von diesem Spiel.

Prüfe in der [Übersetzungsübersicht](https://jackboxpatch.de), welche Texte und Stimmen für dein Spiel angeboten werden. Eine fehlende deutsche Sprachausgabe kann zum Stand der Übersetzung gehören. Manche frühere Patches sind [nicht mehr verfügbar](../Wissenswertes/PartyStarterRelease.md).

### Möglichkeit 2: Bei der Installation ist etwas schief gelaufen.

1. Prüfe den [passenden Patch für dein System und deinen Store](https://jackboxpatch.de/downloads).
2. [Aktualisiere den Patch](../Installation/aktualisieren.md) und warte auf den vollständigen Abschluss.
3. Bleibt das Problem bestehen, [setze das Spiel zurück](../Deinstallation/index.md) und installiere den passenden Patch erneut.

Bleiben bereits übersetzte Inhalte trotzdem auf Englisch, [melde uns das Spiel und die betroffenen Texte oder Stimmen](../Wissenswertes/BugReport.md). Bei macOS hilft zusätzlich die [macOS-Fehlerhilfe](MacOSFehlermeldung.md).
