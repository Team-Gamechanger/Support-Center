# Patch entfernen / Spiel zurücksetzen

Du möchtest den Deutsch-Patch deinstallieren? Beende zuerst das Spiel und nutze eine der folgenden Methoden.

<span id="anleitung"></span>

!!! warning "Trivia Murder Party 3"
    Folge zuerst der [besonderen Deinstallationsanleitung](../Spiele/trivia-murder-party-3.md#deinstallation). Die Steam-Dateiprüfung allein entfernt nicht alle zusätzlichen Patchdateien.

## Mit Jackbox Utility { #deinstallation-der-deutsch-patches-mit-jackbox-utility }

Diese Methode gilt für **Steam-Spiele**. Für Epic Games nutze die [Schritte weiter unten](#deinstallation-der-deutsch-patches-auf-epic-games).

1. Öffne **Optionen** im Hauptmenü von Jackbox Utility. Falls du in **Suche ein Spiel** landest, führt der Pfeil oben links zurück ins Hauptmenü.
2. Gehe in den Reiter **Spiele im Besitz**.
3. Klicke beim entsprechenden Spiel auf den :arrows_counterclockwise: **Pfeil** und dann auf **Bestätigen**.
4. Warte, bis die Steam-Dateiprüfung abgeschlossen ist.

## Über Steam { #deinstallation-der-deutsch-patches-auf-steam }

1. Rechtsklicke auf das Spiel in deiner Steam-Bibliothek.
2. Öffne **Eigenschaften → Installierte Dateien**.
3. Klicke auf **Spieldateien auf Fehler überprüfen …** und warte auf den Abschluss.

## Über Epic Games { #deinstallation-der-deutsch-patches-auf-epic-games }

1. Öffne deine Epic-Games-Bibliothek.
2. Klicke auf die **drei Punkte** beim entsprechenden Spiel.
3. Wähle **Verwalten**.
4. Klicke bei **Dateien überprüfen** auf **Überprüfen** und warte auf den Abschluss.

## Nach der Dateiprüfung

Die Dateiprüfung stellt fehlende oder veränderte Originaldateien wieder her. **Zusätzliche Patchdateien werden dadurch nicht zuverlässig entfernt.** Beachte besondere Deinstallationshinweise zum Patch.

Starte das Spiel ohne erneute Patchinstallation. Funktioniert es wieder, kannst du den [Patch mit Jackbox Utility neu installieren](../Installation/JackboxUtility.md). Bei weiteren Problemen [melde dich bei uns](../Wissenswertes/BugReport.md).
