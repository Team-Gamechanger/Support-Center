# Patch aktualisieren und Version prüfen

Wir aktualisieren unsere Übersetzungen und ergänzen Inhalte und deutsche Stimmen. Ein Update des Originalspiels kann Patchdateien überschreiben. Beende das Spiel vor einer erneuten Installation.

## Mit Jackbox Utility aktualisieren

1. Installiere zunächst verfügbare Updates des Spiels in deinem Store.
2. Öffne Jackbox Utility und wähle den Server **Jackbox auf Deutsch**.
3. Öffne **Patche ein Spiel** und installiere die dort angebotenen Patchupdates für dein Spiel. Warte, bis die Installation abgeschlossen ist.
4. Starte das Spiel erneut.

Ein Update von **Jackbox Utility selbst** ersetzt kein Patchupdate. Wird der Patch nicht angeboten, prüfe die [Spielerkennung und Serverauswahl](../Problembehebung/JackboxUtility.md).

## Manuell aktualisieren

Lade den aktuellen passenden Patch von der [Download-Seite](https://jackboxpatch.de/downloads) und installiere ihn erneut nach der Anleitung für [Windows](Windows.md) oder [macOS](macOS.md). Beachte dabei die Hinweise zum jeweiligen Spiel.

Bei **Trivia Murder Party 3** kann nach einem Spielupdate die [erneute Einrichtung des deutschen Online-Contents](../Spiele/trivia-murder-party-3.md#nach-einem-update) nötig sein.

## Build-Nummer vergleichen { #build-nummer }

Wenn sich das Spiel öffnen lässt, findest du bei den entsprechend gekennzeichneten Party Packs im Hauptmenü eine Build-Nummer. Die Build-Nummer hat das Schema **[Build des Spiels].[Build des Patches]-DE**, beispielsweise `5.2-DE`.

Vergleiche die Anzeige mit den Angaben für **dasselbe Spiel** in Jackbox Utility oder auf unserer [Übersetzungsübersicht](https://jackboxpatch.de). Wird dort etwa `5.3-DE` angeboten, ist der Patch neuer. Nicht jedes Spiel zeigt seine Version auf dieselbe Weise an.

Wenn das Spiel gar nicht startet, überspringe diesen Vergleich und nutze die [Hilfe bei Startproblemen](../Problembehebung/SpielStartetNicht.md).

## Hat es funktioniert?

Prüfe nach dem Start die zuvor fehlenden oder veralteten Inhalte. Bei weiterhin englischen Texten hilft dir [Spiel oder Controller teilweise auf Englisch](../Problembehebung/UnvollstaendigeUebersetzung.md). Bleibt das Problem bestehen, [melde es uns](../Wissenswertes/BugReport.md).
